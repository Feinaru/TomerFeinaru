Accessibility Statement

Last updated: July 20, 2026

We value equal and convenient access to this website. It was built with the aim of following accepted accessibility guidelines and Israeli Standard 5568.

Accessibility features

  • Navigate with Tab, go back with Shift+Tab, activate controls with Enter, and close dialogs with Esc.
  • Semantic headings and text alternatives for visual content.
  • Clear contrast and focus indicators.
  • Responsive display for desktop, tablet and mobile.
  • Tools for larger text, high contrast and highlighted links.
